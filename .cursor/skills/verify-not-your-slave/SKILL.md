# Verify not-your-slave

**not-your-slave** is an eve agent app: one page at `/` (chat left, mindlog right), one durable session, HTTP API on the same origin. Verification starts a real `eve dev` server and drives real controls — no test-only routes.

Harness: **`.cursor/skills/verify-not-your-slave/helpers/verify-nys`** (launch, doctor, drive, cleanup). Browser scenarios use Chrome via `lib/cdp.mjs` (zero Playwright dependency). Most scenarios are headless; **`push-notify` uses headed Chrome** on the VM desktop (`DISPLAY` required).

## Launch

**Node.js >= 24** required. The helper prepends nvm Node 24 when `/exec-daemon/node` is older.

```bash
H=.cursor/skills/verify-not-your-slave/helpers/verify-nys
$H launch --port 2000 --run-id my-run
```

What launch does:

- Prints `waiting for http://127.0.0.1:<port>/ (up to 60s)…` while polling readiness (poll errors are silent; state is written only after the server answers).
- On failure, prints `node -v`, the `dev.log` path, and the last 50 log lines.
- Isolates `MINDLOG_FILE` and `PUSH_FILE` under `.cursor/skills/verify-not-your-slave/.run/<run-id>/data/`.
- Writes **`agent/sandbox.ts`** scaffolding (`justbash()` backend) unless one already exists without the verification marker. Use `--sandbox real` to skip.
- Clears **only** `.eve/.workflow-data` (stale session state); never deletes `.eve/dev-runtime`.
- Runs `npm run dev -- --port <port> --no-ui`; `EVE_DEV=1` keeps localhost open (no Basic auth).
- Loads **`.env.local`** from the repo root when present, else **`.env`** (`AI_GATEWAY_API_KEY`, `VAPID_*`, etc.).
- Records state in `.cursor/skills/verify-not-your-slave/.run/<run-id>/state.env`.

**Readiness:** `GET /` returns 200 with `id="composer"` and `id="mindlog"`.

**Teardown:** `$H cleanup` — kills the **PID from state**, removes sandbox scaffold if ours, deletes the run dir, **never** deletes `evidence/`.

**Isolation:** One instance per port. Use `--port 2001` for side-by-side runs. Do not drive a port you did not launch.

## Doctor

```bash
$H doctor
```

Pass: process alive, `/` has composer + mindlog markers, `/api/session` and `/api/mindlog` answer, mindlog file exists. Lists **credentials** (health check, not a grade — also on every `proof.html`):

| Credential | Env vars | When required |
| --- | --- | --- |
| AI gateway | `AI_GATEWAY_API_KEY` or `VERCEL_OIDC_TOKEN` in `.env.local` or `.env` | Live model replies, agent `said`/`thought` |
| VAPID | `VAPID_PUBLIC_KEY` + `VAPID_PRIVATE_KEY` (+ optional `VAPID_SUBJECT`) | `push-notify` only (headed Chrome) |

Each drive check is **passed**, **failed**, or **blocked** (`need <env var>`). A scenario with any failed or blocked check exits non-zero.

## Drive

```bash
$H drive --list
$H drive chat
$H drive conversation-log
$H drive entry-page
$H drive mindlog-panel
$H drive photo-persist
$H drive push-notify
$H drive pwa-install
$H drive say-limits
$H drive send-photo
$H drive text-persist
$H drive wake-it
```

`--list` is the map. Names above match that listing. Each scenario writes `evidence/<scenario>/<run-id>/result.json` plus screenshots. Run `doctor` first.

### Stable UI handles (`agent/lib/page.ts`)

| Control | Handle |
| --- | --- |
| Chat input | `#input` |
| Send | `#composer button[type=submit]` |
| Attach | `#attach` → `#files` (`accept` image types) |
| Previews | `#previews img` |
| Conversation log | `#chat .msg.me`, `#chat .msg.it`, `#chat .woke` |
| User images in log | `#chat .msg.me img.pic` |
| Status | `#status` |
| Wake it | `#think` |
| Mindlog pane | `#mindlog`, `#mindlog-open` |
| Notify | `#notify` |

### HTTP shortcuts

```bash
$H api POST /api/say '{"message":"hello"}'
$H api POST /api/think
$H api GET '/api/mindlog?limit=20'
curl -fsS "$BASE_URL/manifest.webmanifest"
```

Multipart photos (same as the page): `message` + `images` file parts on `POST /api/say`.

## Evidence (local only — not committed)

Proof is generated by `verify-nys drive` on your machine. See [`evidence/README.md`](evidence/README.md).

```
.cursor/skills/verify-not-your-slave/evidence/<scenario>/<run-id>/
  proof.html           human skim (from lib/proof-index.mjs)
  result.json          every check: pass / fail / blocked + meta
  *.png                screenshots
.cursor/skills/verify-not-your-slave/evidence/_runs/<run-id>/
  proof.html           rollup across scenarios from the same launch
```

**Proof standards:** real user path; capture action **and** resulting state **and** side effects (`heard` bytes in `/api/mindlog`, `sent >= 1` for push); scenarios use soft waits so one timeout does not abort remaining checks; after `cleanup`, evidence must still exist locally.

## Cleanup

```bash
$H cleanup
```

Kills recorded PID only (never `pkill eve`). Removes run dir and verification `agent/sandbox.ts` when marked. Keeps `evidence/`. Run after failed attempts.

## Helpers

| Path | Role |
| --- | --- |
| `helpers/verify-nys` | launch, doctor, drive, api, cleanup |
| `helpers/drive.mjs` | scenario runner |
| `lib/cdp.mjs` | Chrome CDP (`withPage`; headed for `push-notify`) |
| `lib/fixtures.mjs` | `pngFixture()` for real PNG bytes |
| `scenarios/*.mjs` | one feature per file |

Example:

```bash
H=.cursor/skills/verify-not-your-slave/helpers/verify-nys
$H launch --port 2001 --run-id prove
$H doctor
$H drive conversation-log
$H drive text-persist    # #chat user restore when /api/session has an id after send
$H drive wake-it         # agent said blocked without AI credential
$H cleanup
```

Feature recipes: [`features/README.md`](features/README.md). Keep them aligned with `verify-nys drive --list`.
