chuyeowego/not-your-slave

An agent that thinks
for itself

It runs when nobody asked. It writes everything it hears, thinks, says, and does to an append-only mindlog — a file, or Postgres when DATABASE_URL is set — and wakes itself every fifteen minutes to continue its own thread of thought.

Source on GitHub · built on eve · after headlong

Six commits, six explainers

Each commit below adds one idea, and each has a page explaining it: the background you need, the core intuition with diagrams, a walkthrough of the code, and five questions to check you actually followed it.

Read them in order. They are written to be read by someone who has never built an agent. After these six commits the running tree is one TIMELINE session, mindlog-in-sandbox.ts, and optional DATABASE_URL — not the architecture 04–06 describe.

Running it

git clone git@github.com:chuyeowego/not-your-slave.git
cd not-your-slave && npm install
echo "AI_GATEWAY_API_KEY=vck_..." > .env.local
npm run dev        # http://127.0.0.1:2000 – chat left, mindlog right

npm run build && npm start   # and now the heartbeat actually fires

eve dev never fires cron, so during development the heartbeat is a button. The built server runs the scheduler, which is where the agent becomes autonomous. Commit 4 explains why that distinction matters more than it sounds.
